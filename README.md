# リアルタイム議事録（Mac）

会議をリアルタイムで書き起こし、終了と同時に議事録（Markdown / PDF）を作る、無料の Mac アプリです。
音声認識もAIも Mac の中で動き、会議の内容を外部に送りません。

**紹介とダウンロードは、こちらのページから:**
https://studio-kplus.ns-laboratory.com/realtime-memo/

このリポジトリは、アプリのファイル（Releases の dmg）の置き場所です。ソースコードは含みません。
利用しているソフトウェアのクレジットは [NOTICE.md](NOTICE.md) を参照してください。
